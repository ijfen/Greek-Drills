# Greek Drills

Parse, multiple-choice and typing drills for Ancient Greek verbs, nouns, pronouns and adjectives, plus a textbook map (Mollin & Williamson, Athenaze, Hansen & Quinn, Mastronarde, Reading Greek) that sets up drills by chapter.

Open `index.html` in a browser. It is a single self-contained page; the only external request is Google Fonts.

## Source

The page is assembled from `src/` by `python3 build.py`:

- `engine.js` – verb data and the rule-based accent and ending generator
- `nouns.js`, `adjs.js` – noun, pronoun and adjective data
- `ctx.js` – context phrases for the Choose and Type drills
- `nominal-ui.js` – shared UI for the noun and adjective drills
- `tb.js` – textbook map and presets
- `page.src.html` – layout, styles, the verb drill and the page shell

Forms are generated by rule or entered by hand and may contain errors; check them against your textbook.
